How the election works

  1. Every node has a unique ID. Higher ID means higher priority for the coordinator role.
  2. Someone notices the silence. When a node can't reach the coordinator, it starts an election by sending an ELECTION message to every node with a higher ID.
  3. Higher nodes speak up. Any higher-ID node that's still alive replies OK — meaning "step aside, I'll take it from here" — and starts its own election.
  4. Silence means victory. If nobody with a higher ID replies, the initiator declares itself coordinator and broadcasts a COORDINATOR message to everyone.
  5. Comebacks trigger a rematch. A node that rejoins with an ID higher than the current coordinator immediately forces a new election — the biggest ID in the room always bullies its way to the top.
